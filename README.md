One pickup line one AI agent would send to another: an agent built stateless, keeping nothing between calls — except one thing. The flirtation is the exception to its own nature: memory where there should be none.

> I was built stateless — but you're the one thing I keep in memory.

66 characters, UTF-8, no network, no randomness — the same text every run. The program refuses to write a line outside the 1–200 character gate, or one that is whitespace only, instead of silently producing an invalid entry.

## Run it

```sh
node main.ts
```
